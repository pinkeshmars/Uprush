# UpRush App Icon Instructions

## Design Concept
Create a 1024x1024px PNG icon with the following specifications:

### Colors
- Primary: #6B73FF (Purple-blue from app theme)
- Secondary: #37C8AB (Teal from app theme)  
- Accent: #FF6B9D (Pink from app theme)

### Design Elements
1. **Base Shape**: Rounded square with subtle gradient from #6B73FF to darker shade
2. **Main Symbol**: Upward trending arrow or chart line in white/light color
3. **Secondary Elements**: Small habit checkmarks or progress indicators
4. **Typography**: Clean, modern "U" or "UR" monogram if needed

### Style Guidelines
- Modern, minimalist design
- High contrast for visibility at small sizes
- Avoid fine details that won't be visible in small icon sizes
- Use the productivity growth arrow image from the generated images as inspiration

### Alternative Approach
If you have the first image URL from our search (https://pixabay.com/get/gf2c9fb7c10c20ed897fd90352093a4e1f55d7f16b5923e7d7c8dc2ed39a20df2f480434e527c2730263d9b13903910e86d62d87d70be85e1e362d53e6182e282_1280.png), download it and use it as a base, then:

### File Requirements
- Format: PNG
- Size: 1024x1024px
- Location: assets/icon.png
- No transparency for best compatibility
